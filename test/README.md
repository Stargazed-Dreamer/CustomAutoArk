# test/ — 临时试验脚本目录

> ⚠️ **本目录不是正式测试目录！** 正式的单元测试位于 [`tests/`](../tests/)（复数）。

## 用途

本目录用于存放开发期间的**临时试验脚本、手动调试代码、截图样本**等，
不参与 CI、不参与构建、不被 `pytest` 收集。

## 与 `tests/` 的区别

| 项 | `test/`（本目录，单数） | `tests/`（复数） |
|----|------------------------|------------------|
| 性质 | 临时脚本、调试代码 | 正式单元测试 |
| 框架 | 无约束，可任意写 | pytest，遵循 `pytest.ini` 配置 |
| CI | 不运行 | 在 `.github/workflows/ci.yml` 中自动运行 |
| 命名 | 任意 | `test_*.py` / `Test*` / `test_*` |
| 是否入库 | 已被 `.gitignore` 排除（除 README） | 入库 |
| 依赖 | 可依赖真实 ADB / OCR / 模拟器 | mock 重依赖，轻量运行 |

## 当前内容

| 文件 | 说明 |
|------|------|
| `test.py` | 临时调试脚本 |
| `ocr.py` | OCR 识别调试脚本 |
| `data.py` | 数据相关调试脚本 |
| `a.png` / `b.png` / `c.png` / `素材.png` | 调试用截图样本 |

## 注意

- 本目录除 `README.md` 外的内容已被 `.gitignore` 排除，不会进入版本库
- 新功能开发时如有临时验证需求，可在此目录创建脚本，但**不要**把正式测试放在这里
- 正式测试请放在 `tests/` 目录，遵循现有 `test_*.py` 命名约定
- 详见 [docs/testing.md](../docs/testing.md)
